description: Move code, tests or model text to a new place without changing what the
  product does, and keep every reference between model, code and tests pointing at
  the right thing. Use whenever a change splits or merges a file or module, moves
  a function, a test or a model element to another file or folder, renames a module
  or a file, or reorganises a directory; also when an issue is declared a restructuring
  or a refactoring, and before a large file is split so that its parts can be owned
  and tested separately.
